# تقرير فحص إصدار OT Laundry — المرحلتان 9 و13

## المرحلة 9 — الحضور والرواتب
- أضيفت قواعد احتساب مستقلة لكل فرع: أيام العمل المحاسبية، ساعات اليوم، معامل الإضافي، معامل خصم التأخير، ومعامل خصم الغياب.
- أضيفت معاينة لفترة المسير قبل الإنشاء.
- احتساب التأخير من وقت الحضور وبداية الوردية وفترة السماح.
- احتساب الإضافي من وقت الانصراف ونهاية الوردية، مع دعم الوردية التي تعبر منتصف الليل.
- خصم الغياب من الأيام المسجلة غيابًا فقط، مع استثناء الإجازات المعتمدة.
- أضيفت مكونات الحضور إلى مفردات الراتب كسجلات منفصلة، مع حفظ صافي الراتب في PostgreSQL.
- تتم إعادة حساب ملخص الحضور عند إرسال طلب إنشاء المسير، ولا يتم الوثوق بقيم المعاينة المرسلة من العميل.
- جميع RPCs الجديدة SECURITY INVOKER، والتنفيذ متاح لـ authenticated فقط، وممنوع عن anon/public.

## اختبار قاعدة البيانات
- تم تشغيل سيناريو QA داخل معاملة تجريبية: موظف تجريبي، وردية، سجل حضور متأخر، سجل غياب، احتساب التأخير والإضافي والغياب، إنشاء مسير، والتحقق من حفظ مكونات الحساب.
- تمت إعادة المعاملة باستخدام ROLLBACK.
- تم التحقق بعد الاختبار من عدم بقاء موظف أو وردية أو مسير QA.
- تم التحقق من أن RPCs الجديدة ليست SECURITY DEFINER، وأن `anon` لا يملك EXECUTE وأن `authenticated` يملكه.
- لا توجد بيانات موظفين حالية في الفرع وقت تنفيذ اختبار المعاينة؛ لذلك لم تتم مقارنة النتائج بسجلات تشغيل فعلية.

## المرحلة 13 — حزمة Windows
- أضيف سكربت بناء Windows باستخدام PyInstaller بنمط onedir.
- أضيف إعداد نسخة Portable مع `portable.flag` ومجلد بيانات مستقل.
- أضيف ملف Inno Setup لبناء Installer واختصارات Start Menu وسطح المكتب.
- أضيف دليل المستخدم وإعداد الاتصال.

## ما لم يتم اختباره هنا
- بيئة العمل الحالية Linux؛ لذلك لم يتم إنشاء أو تشغيل ملف EXE خاص بـ Windows فعليًا.
- لم يتم اختبار Microsoft Edge WebView2 أو الطباعة على طابعة حرارية فعلية.
- يجب تشغيل `BUILD_WINDOWS.bat` على جهاز Windows 10/11، ثم اختبار Installer وPortable وتسجيل الدخول والطباعة قبل توزيع النسخة.
- فحص Supabase Security Advisor ما زال يظهر تحذيرين قديمين لدالتي تحديث حالة القطعة وتسليم الفاتورة (SECURITY DEFINER)، وتحذير تعطيل حماية كلمات المرور المسربة. لا تتعلق هذه التحذيرات بدوال المرحلة 9 الجديدة.
