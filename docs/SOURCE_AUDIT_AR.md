# تقرير مراجعة المصدر الأصلي

## نتيجة الفحص
- المصدر الأصلي تطبيق Python/Flask بواجهة HTML/CSS/JavaScript.
- ملف `app.py` كبير ومركزي (نحو 5,200 سطر و153 مسارًا بحسب الفحص السابق)، ويجمع عددًا كبيرًا من وظائف المحاسبة والمخازن والمبيعات.
- طبقة البيانات موجودة في `database.py`، مع اعتماد سابق على SQLite وبوابة SQL Gateway مرتبطة بمشروع Supabase قديم.
- توجد قوالب وأسماء وشعارات مرتبطة بشركة المجد ووظائف غير مطلوبة في مغسلة الملابس.

## مخاطر لا يجوز نقلها
1. ملفات الإعداد القديمة تشير إلى مشروع Supabase السابق، ولا يجوز إعادة استخدامها مع OT Laundry.
2. تنفيذ SQL Gateway القديم لا يطابق آلية التحقق من الرمز التي يتوقعها عميل قاعدة البيانات؛ لذلك لا يعاد استخدامه.
3. نسخة الأرشيف تحتوي على `instance/secret.key`؛ يجب اعتبار المفتاح مكشوفًا وعدم تضمينه في المشروع الجديد.
4. لا يجوز تضمين Service Role Key داخل تطبيق Windows.
5. جداول ومفاهيم المندوبين والمخازن التجارية والمبيعات ليست جزءًا من إصدار المغسلة الأول.

## قرار إعادة الاستخدام
- عدم تعديل ملفات المصدر الأصلي.
- إنشاء مشروع مستقل `OT-Laundry`.
- إعادة استخدام المعرفة العامة بالتقنية فقط (Python/Flask وواجهة RTL)، مع بناء طبقة مصادقة وواجهة جديدة.
- لا توجد بيانات قديمة من El Magd في قاعدة OT Laundry.

## الحالة الحالية
تم إنشاء هيكل أولي لتطبيق Windows المحلي وشاشات الدخول والإعداد الأولي وإدارة المستخدمين. لا تزال وحدات الكاشير والفواتير والتشغيل والمدفوعات والتقارير والموارد البشرية غير منفذة، ولذلك لا تعتبر النسخة جاهزة للتشغيل التجاري.
